# Estructura del plan, tratamiento de datos y auditoría final

## 1. Investigación resumida

Al armar una carpeta conceptual o documento final, la investigación resumida incluye todo lo investigado durante el proceso, no solo la primera etapa: origen del proyecto, justificación de la elección, investigación exploratoria, mercado, competencia, consumidor, materiales, procesos, precios, costos, canales, validaciones, sustentabilidad, fuentes y uso de IA. No repetir después esa información dentro del plan.

## 2. Estructura del Plan de Marketing

- **Portada** e **Índice**
- **1. Investigación resumida** (si el formato académico la pide fuera del plan)
- **2. Plan de Marketing**
  - 2.1 Resumen ejecutivo: debe permitir entender el negocio en menos de una página. Incluye empresa, producto, mercado, diferencial, estrategia, precio, distribución, comunicación y crecimiento.
  - 2.2 Análisis de mercado: categoría, país/mercado, competencia, consumidor, segmentación, mercado meta, oportunidad.
  - 2.3 Análisis situacional: matrices seleccionadas, resultados y conclusión conjunta.
  - 2.4 Marketing estratégico: ventaja competitiva, estrategia de valor, crecimiento, integración, estrategia competitiva, posicionamiento y declaración.
  - 2.5 Marketing operativo: producto, precio, distribución, comunicación.
  - 2.6 Control: indicadores y decisiones.
- **3. Conclusiones.** En trabajos académicos, explicar cómo evolucionó el proyecto y qué decisiones lo transformaron. No convertirla en un resumen del plan.
- **4. Referencias.** Solo fuentes realmente utilizadas.

## 3. Tratamiento de información incierta

Clasificar cada dato:
- **Confirmado:** existe evidencia.
- **Inferido:** conclusión razonable a partir de información existente.
- **Hipótesis:** debe validarse.
- **Decisión:** elección estratégica.
- **Pendiente:** falta información.

Nunca presentar una hipótesis como hecho.

## 4. Investigación externa

Si se pide investigación, buscar fuentes actuales. Prioridad: fuentes oficiales, fabricantes, organismos, papers, publicaciones comerciales, marketplaces, prensa especializada y, como evidencia cualitativa, foros y comunidades. Para precios, indicar la fecha de consulta. Para mercado, no extrapolar datos demasiado generales a nichos específicos.

## 5. Uso de inteligencia artificial

Puede: ordenar información, crear preguntas, comparar alternativas, buscar fuentes, analizar competencia, revisar coherencia, mejorar redacción, detectar repeticiones y controlar referencias.

No debe: inventar datos, fingir investigación, fabricar entrevistas, crear estadísticas ni reemplazar validaciones técnicas.

Si el trabajo lo requiere, documentar herramienta utilizada, finalidad, prompts principales y forma de verificación.

## 6. Lista de control (auditoría final)

**Investigación**
- [ ] ¿Se entiende de dónde nace el proyecto?
- [ ] ¿Se explica por qué fue elegido?
- [ ] ¿La investigación incluye todo el proceso?
- [ ] ¿Se distinguen datos internos y externos?
- [ ] ¿Las fuentes están citadas?

**Mercado**
- [ ] ¿Está definido el país?
- [ ] ¿El mercado meta es específico?
- [ ] ¿No se inventaron edades o ingresos?
- [ ] ¿Tipo de mercado y variables de segmentación están diferenciados?

**Análisis**
- [ ] ¿Las matrices tienen información suficiente?
- [ ] ¿Cada matriz genera una conclusión?
- [ ] ¿Existe conclusión global?

**Estrategia**
- [ ] ¿Hay ventaja competitiva?
- [ ] ¿Hay estrategia de valor?
- [ ] ¿Hay crecimiento?
- [ ] ¿Hay integración si corresponde?
- [ ] ¿Hay estrategia competitiva?
- [ ] ¿Existe declaración de posicionamiento?

**Marca**
- [ ] ¿Tiene personalidad?
- [ ] ¿Tiene valores?
- [ ] ¿Tiene relación con el cliente?
- [ ] ¿El físico de la marca coincide con el producto?

**Producto**
- [ ] ¿La calidad está expresada mediante especificaciones?
- [ ] ¿Se define packaging?
- [ ] ¿Se define contenido?
- [ ] ¿Se define servicio?
- [ ] ¿Se define línea futura?

**Precio**
- [ ] ¿Existe costo?
- [ ] ¿Existe precio final?
- [ ] ¿Se analizó la competencia?
- [ ] ¿La estrategia de precio está definida?

**Distribución**
- [ ] ¿Canal directo/indirecto?
- [ ] ¿Sistema?
- [ ] ¿Cobertura?
- [ ] ¿Logística?

**Comunicación**
- [ ] ¿Existe mensaje principal?
- [ ] ¿Existe estrategia de canal?
- [ ] ¿Herramientas?
- [ ] ¿Tono?
- [ ] ¿Coherencia entre medios?

**Control**
- [ ] ¿Hay indicadores reales?
- [ ] ¿Cada indicador permite tomar decisiones?

**Redacción**
- [ ] ¿Está en tercera persona?
- [ ] ¿Usa terminología profesional?
- [ ] ¿Evita explicar teoría innecesariamente?
- [ ] ¿Evita justificar todas las opciones descartadas?
- [ ] ¿Evita escribir por la negativa?
- [ ] ¿No repite información?

**Coherencia**
- [ ] ¿Producto, mercado, precio y comunicación cuentan la misma historia?
- [ ] ¿No cambió el mercado meta entre secciones?
- [ ] ¿La propuesta de valor coincide con el precio?
- [ ] ¿La identidad coincide con materiales y packaging?
- [ ] ¿Las conclusiones surgen realmente del análisis?

## 7. Prompts de activación

**Para construir un plan:**

> Quiero desarrollar un emprendimiento y construir un Plan de Marketing profesional usando esta skill. Primero haceme una descarga inicial ordenada de toda la información que ya tengo. Después clasificá lo que está confirmado, lo que falta validar y las decisiones pendientes. Haceme preguntas por rondas, sin repetir información que ya te di. No inventes datos. Cuando tengamos información suficiente, construí investigación resumida, análisis de mercado, análisis situacional con matrices y conclusión, marketing estratégico, identidad de marca, producto, precio, distribución, comunicación, control y conclusiones. El Plan formal debe estar redactado en tercera persona, con lenguaje profesional, decisiones explícitas y justificaciones breves.

**Para revisar un trabajo existente:**

> Revisá este emprendimiento o Plan de Marketing con la metodología de esta skill. No lo reescribas primero. Detectá: información faltante, contradicciones, decisiones sin justificar, teoría innecesaria, matrices incompletas, falta de estrategia de valor, integración, posicionamiento, errores de segmentación, inconsistencias entre producto/precio/distribución/comunicación y datos inventados o no respaldados. Después proponé una lista priorizada de correcciones.

## 8. Estándar de redacción final

El documento debe sentirse como una herramienta profesional que una persona nueva en la empresa pueda recibir y entender qué es el emprendimiento, qué quiere lograr, a quién vende, cómo compite y qué debe hacer. No debe sentirse como una colección de definiciones de marketing pegadas a un caso.
