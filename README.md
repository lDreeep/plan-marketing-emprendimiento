# Plan de Marketing para emprendimientos

Skill para Claude que convierte una idea, emprendimiento o producto existente en un Plan de Marketing profesional, coherente y justificado.

## Contenido

- `plan-marketing-emprendimiento/SKILL.md`: principios, modos de trabajo y flujo de preguntas por rondas.
- `plan-marketing-emprendimiento/references/`: cuestionarios, análisis y estrategia, marketing operativo, estructura del plan y checklist de auditoría.

## Cómo usarla

1. Comprimí la carpeta `plan-marketing-emprendimiento` en un zip.
2. En Claude, andá a Configuración → Capacidades → Skills y subí el zip.
3. Pedile a Claude que arme el plan de marketing de tu emprendimiento.
